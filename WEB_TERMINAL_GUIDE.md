# Руководство по веб-терминалу

## Обзор

Веб-терминал предоставляет полнофункциональный интерактивный доступ к удаленным хостам прямо из браузера. Работает через WebSocket и gsocket в интерактивном режиме.

## Возможности

- ✅ Полноценная эмуляция VT100 терминала
- ✅ Поддержка цветов, форматирования, cursor control
- ✅ Работа через WebSocket (real-time)
- ✅ Автоматическое переподключение
- ✅ Адаптивный размер терминала
- ✅ Распознавание ссылок
- ✅ История команд (стрелки вверх/вниз)
- ✅ Tab-completion (если поддерживается на хосте)

## Как использовать

### Шаг 1: Открыть терминал

1. Перейдите на страницу **Hosts Management**
2. Найдите нужный хост в списке
3. Нажмите кнопку **"Terminal"** в столбце Actions
4. Откроется страница веб-терминала

Альтернативно, можно открыть напрямую:
```
http://localhost:3000/terminal/{host_id}
```

### Шаг 2: Подключение

После открытия страницы терминал автоматически:
1. Устанавливает WebSocket соединение
2. Подключается к хосту через gsocket
3. Отображает приглашение командной строки

Вы увидите:
```
GSocket Web Terminal
============================================================

Connecting to host #1...
✓ WebSocket connection established
Waiting for host connection...

Connected to web-server-01

user@host:~$
```

### Шаг 3: Работа с терминалом

Используйте терминал как обычную командную строку:

```bash
# Проверка системы
uname -a

# Просмотр файлов
ls -la

# Редактирование файлов
nano /etc/hosts

# Запуск скриптов
./script.sh

# Установка пакетов
sudo apt update && sudo apt install -y htop
```

### Кнопки управления

- **Reconnect** - переподключиться к хосту
- **Clear** - очистить экран терминала
- **Back to Hosts** - вернуться к списку хостов

## Архитектура

### Как это работает

```
Browser (xterm.js)
    ↕ WebSocket
Backend (FastAPI)
    ↕ stdin/stdout
gs-netcat -i (interactive mode)
    ↕ Encrypted connection
GSRN Relay Network
    ↕ Encrypted connection
Remote Host (gs-netcat -l)
    ↕
/bin/bash
```

### Технические детали

**Frontend:**
- xterm.js 5.3.0 - эмулятор терминала
- xterm-addon-fit - автоматическое изменение размера
- xterm-addon-web-links - распознавание ссылок
- WebSocket API - real-time соединение

**Backend:**
- FastAPI WebSocket endpoint: `/api/terminal/ws/{host_id}`
- asyncio для асинхронной обработки I/O
- gsocket процесс в интерактивном режиме

**GSocket команда:**
```bash
gs-netcat -k /tmp/secret -i -w 10
```

Флаги:
- `-k` - секрет из файла (безопасно)
- `-i` - интерактивный режим (PTY)
- `-w 10` - ждать подключения до 10 секунд

## Переменные окружения

### GS_HOST

Если у хоста указан IP адрес, устанавливается `GS_HOST`:

```bash
GS_HOST=192.168.1.100 gs-netcat -s секрет -iw
```

Это указывает gs-netcat напрямую подключаться к этому хосту.

### GSOCKET_ARGS

Для кастомных GSRN серверов:

```bash
GSOCKET_ARGS="-s relay.example.com:443" gs-netcat -k /tmp/secret -iw
```

## Troubleshooting

### Проблема: "Connecting..." зависает

**Причины:**
1. Хост не запущен или offline
2. Секрет не совпадает
3. GSRN недоступен

**Решение:**
```bash
# Проверить что хост запущен
ssh user@host "ps aux | grep gs-netcat"

# Проверить секрет в панели и на хосте

# Попробовать переподключиться (кнопка Reconnect)
```

### Проблема: Терминал не отвечает на ввод

**Причины:**
1. WebSocket соединение потеряно
2. gs-netcat процесс завис
3. Буфер переполнен

**Решение:**
```bash
# 1. Проверить статус соединения (внизу страницы)
# 2. Нажать "Reconnect"
# 3. Если не помогает - перезапустить хост агент:

ssh user@host "pkill gs-netcat"
ssh user@host "gs-netcat -l -s SECRET -e /bin/bash -D"
```

### Проблема: Кириллица отображается неправильно

**Причина:** Неправильная кодировка

**Решение:**
```bash
# Проверить locale на хосте
locale

# Установить UTF-8
export LANG=en_US.UTF-8
export LC_ALL=en_US.UTF-8

# Сделать постоянным
echo 'export LANG=en_US.UTF-8' >> ~/.bashrc
```

### Проблема: Цвета не работают

**Причина:** TERM не установлен

**Решение:**
```bash
# Установить TERM
export TERM=xterm-256color

# Сделать постоянным
echo 'export TERM=xterm-256color' >> ~/.bashrc

# Проверить
echo $TERM
```

### Проблема: "Not authenticated" ошибка

**Причина:** Нет токена или токен истек

**Решение:**
1. Вернуться на /login
2. Войти заново
3. Токен сохранится в localStorage
4. Открыть терминал снова

## Безопасность

### Рекомендации:

1. **Используйте сильные пароли** для учетных записей на хостах
2. **Не оставляйте терминал открытым** без присмотра
3. **Закрывайте сессию** после работы
4. **Ограничьте права** пользователя gs-netcat на хосте
5. **Мониторьте логи** подключений

### Ограничения прав на хосте:

```bash
# Создать ограниченного пользователя
sudo useradd -m -s /bin/bash gsocket_user

# Запустить gs-netcat под этим пользователем
sudo -u gsocket_user gs-netcat -l -s SECRET -e /bin/bash -D

# Настроить sudo только для нужных команд
echo 'gsocket_user ALL=(ALL) NOPASSWD: /usr/bin/apt, /bin/systemctl' | sudo tee /etc/sudoers.d/gsocket
```

## Ограничения

### Что НЕ работает:

❌ Интерактивные приложения требующие специфичного TTY (некоторые)
❌ Двухфакторная аутентификация через терминал
❌ Графические приложения (X11 forwarding)
❌ Передача файлов (используйте SCP/SFTP отдельно)

### Что работает:

✅ Все стандартные команды bash
✅ Текстовые редакторы (nano, vim, emacs)
✅ Интерактивные утилиты (top, htop, less)
✅ SSH из терминала к другим хостам
✅ Package managers (apt, yum, etc.)
✅ Скрипты любой сложности

## FAQ

**Q: Можно ли открыть несколько терминалов к одному хосту?**
A: Да, каждый терминал - это отдельная сессия.

**Q: Сохраняется ли история команд?**
A: История bash сохраняется на хосте в ~/.bash_history

**Q: Можно ли копировать/вставлять?**
A: Да, используйте Ctrl+Shift+C / Ctrl+Shift+V или контекстное меню

**Q: Работает ли tab completion?**
A: Да, если настроено на хосте

**Q: Можно ли изменить размер шрифта?**
A: Ctrl++/Ctrl+- в браузере или изменить fontSize в коде

**Q: Поддерживается ли tmux/screen?**
A: Да, но лучше использовать нативные возможности браузера (вкладки)
