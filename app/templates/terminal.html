GSocket Terminal Shortcuts

Terminal Shortcuts

Shortcut Description
Ctrl + Shift + C Copy selected text to clipboard
Ctrl + Shift + V Paste from clipboard
Right Click Copy selection or paste
Ctrl + C Send interrupt signal (SIGINT)
Ctrl + D Send EOF / Exit shell
Ctrl + Z Suspend current process (SIGTSTP)
Ctrl + L Clear screen
Ctrl + A Move cursor to start of line
Ctrl + E Move cursor to end of line
Ctrl + K Cut text from cursor to end of line
Ctrl + U Cut text from cursor to start of line
Ctrl + W Cut previous word
Ctrl + Y Paste cut text
Tab Auto-complete
↑ / ↓ Navigate command history

GSocket Specific

Command Description
~. Disconnect from GSocket (enter tilde dot)
~C Open GSocket command mode
~# Show connection statistics
~s Show socket information
~^Z Background GSocket connection
Note:
• Use Ctrl+Shift+C/V for clipboard copy/paste (browser shortcuts)
• Use Ctrl+C/D/Z for terminal control (sent to remote shell)
• Right-click to copy selected text or paste from clipboard
• All terminal shortcuts (Ctrl+A/E/K/U/W/Y, etc.) are passed through to the remote shell
• GSocket commands starting with ~ must be typed at the beginning of a new line
