# GSocket C2 Panel

Web-панель для централизованного управления рабочими станциями через gsocket (hackerschoice/gsocket).

## 🎯 Реализация gsocket

Интеграция с gsocket выполнена согласно **официальной документации**:

- **Архитектура**: Хосты работают в listen mode (`gs-netcat -l`), панель подключается как клиент
- **Безопасность**: Секреты передаются через временные файлы (`-k` флаг) и хранятся зашифрованными в БД
- **Протокол**: SRP-AES-256-CBC-SHA с 4096-bit prime (end-to-end encryption)
- **Функции**: Поддержка `-w` (wait for listener), `-i` (interactive PTY), `-t` (test connection)

**Важные документы:**
- `INITIALIZATION.md` - автоматическая инициализация БД и создание admin
- `HOST_SETUP_GUIDE.md` - пошаговая инструкция настройки хостов
- `CSV_IMPORT_GUIDE.md` - импорт хостов из CSV файлов (bulk import)
- `EXAMPLE_SCRIPTS_GUIDE.md` - руководство по готовым скриптам администрирования
- `GSOCKET_ARCHITECTURE.md` - архитектура gsocket и как работает подключение
- `WEB_TERMINAL_GUIDE.md` - руководство по веб-терминалу
- `CUSTOM_GSRN_GUIDE.md` - настройка кастомных GSRN серверов
- `TROUBLESHOOTING_LOGIN.md` - решение проблем с входом
- `GSOCKET_IMPLEMENTATION_ISSUES.md` - детальный анализ архитектуры
- `MIGRATION_GUIDE.md` - миграции базы данных

## Возможности

### Управление хостами
- **Добавление, удаление, мониторинг**: Полный контроль над хостами
- **CSV импорт**: Массовое добавление хостов из CSV файлов (bulk import)
- **Автоопределение hostname**: Автоматическое получение реального hostname с хостов
- **Массовые операции**: Проверка доступности и получение hostname для нескольких хостов одновременно
- **Копирование secrets**: Быстрое копирование gsocket secret в буфер обмена

### Выполнение задач и скрипты
- **Библиотека скриптов**: Создание и управление bash-скриптами для выполнения
- **Готовые примеры**: 6 предустановленных скриптов для администрирования (system info, security audit, disk cleanup, updates, services, network)
- **Параллельное выполнение**: Скрипты выполняются на множестве хостов одновременно
- **ANSI цвета**: Полная поддержка ANSI escape sequences в выводе задач
- **Категоризация**: Организация скриптов по категориям

### Веб-терминал
- **Полнофункциональный терминал**: xterm.js + WebSocket для интерактивной работы
- **Keyboard shortcuts**: Ctrl+Shift+C/V для копирования/вставки, правый клик для быстрого доступа
- **GSocket команды**: Поддержка всех gsocket специфичных команд (~., ~C, ~#, ~s)
- **Цветная поддержка**: 16 ANSI цветов, bold, underline, dim
- **История и навигация**: Полная поддержка Ctrl+A/E/K/U/W/Y, Tab autocomplete

### Мониторинг и логирование
- **Автоматический мониторинг**: Проверка доступности хостов каждые 3 минуты
- **Детальные логи**: Логи всех операций с фильтрацией по уровню и категории
- **Dashboard**: Статистика в реальном времени
- **Экспорт**: Экспорт данных и логов в CSV

### Безопасность
- **Шифрование**: AES-256-GCM для gsocket secrets в БД
- **JWT аутентификация**: Безопасная авторизация с токенами
- **Смена пароля**: Возможность изменения пароля прямо в настройках панели
- **SRP-AES-256-CBC**: End-to-end шифрование через gsocket

### Конфигурация
- **Кастомные GSRN серверы**: Поддержка собственных relay серверов
- **Динамические настройки**: Изменение параметров без перезапуска (14 настроек)
- **Автоматические миграции**: База данных обновляется автоматически
- **Автоматизация развертывания**: Скрипты для обновления и ребилда контейнеров

## Технологический стек

- **Backend**: Python 3.11+, FastAPI
- **Database**: SQLite с SQLAlchemy ORM
- **Frontend**: HTML5, CSS3, Vanilla JavaScript

## Быстрый старт

### 1. Клонирование репозитория

```bash
git clone <repo-url>
cd gs-webpanel
```

### 2. Настройка окружения

Скопируйте файл с переменными окружения:

```bash
cp .env.example .env
```

Отредактируйте `.env` и установите секретные ключи:

```bash
SECRET_KEY=your-secret-key-min-32-chars
ENCRYPTION_KEY=your-encryption-key-32-bytes
```

### 3. Запуск с Docker (рекомендуется)

#### Первый запуск или после обновления


## Использование

### Смена пароля

1. Перейдите в раздел "Settings"
2. В секции "🔐 Security & Account" найдите форму "Change Password"
3. Заполните:
   - **Current Password**: Текущий пароль
   - **New Password**: Новый пароль (минимум 8 символов)
   - **Confirm New Password**: Подтверждение нового пароля
4. Нажмите "Change Password"

**Требования к паролю:**
- Минимум 8 символов
- Рекомендуется использовать комбинацию букв, цифр и спецсимволов

### Добавление хоста

1. Перейдите в раздел "Hosts"
2. Нажмите "+ Add Host"
3. Заполните форму:
   - **Hostname**: Имя хоста (можно автоматически получить позже)
   - **IP Address**: IP адрес (опционально)
   - **GSocket Secret**: Секретный ключ gsocket для подключения
   - **Description**: Описание
   - **Notes**: Заметки
   - **Tags**: Теги для группировки (через запятую)
4. Нажмите "Add Host"

**Дополнительные функции:**
- **Hostname (кнопка)**: Автоматически получить и обновить реальный hostname с хоста
- **📋 (кнопка)**: Копировать gsocket secret в буфер обмена
- **Проверить**: Проверить доступность хоста через gsocket

### Массовые операции с хостами

1. Выберите несколько хостов с помощью чекбоксов
2. Появятся кнопки для массовых операций:
   - **Проверить**: Проверить доступность всех выбранных хостов
   - **Получить Hostname**: Автоматически обновить hostname для всех выбранных хостов
   - **Выполнить скрипт**: Запустить скрипт на всех выбранных хостах
3. Система покажет статистику выполнения (успешно, пропущено, ошибок)

### Создание скрипта

1. Перейдите в "Scripts"
2. Нажмите "+ Add Script"
3. Заполните:
   - **Name**: Название скрипта
   - **Description**: Описание
   - **Content**: Bash-скрипт
   - **Timeout**: Таймаут выполнения (секунды)
4. Нажмите "Add Script"

### Выполнение задачи

1. Перейдите в "Tasks"
2. Нажмите "+ Create Task"
3. Выберите скрипт из списка
4. Выберите целевые хосты (checkbox)
5. Нажмите "Execute Task"
6. Задача будет выполнена параллельно на всех выбранных хостах

### Просмотр результатов

1. В разделе "Tasks" нажмите "View Results" для нужной задачи
2. Увидите детальную информацию:
   - Статус выполнения на каждом хосте
   - Exit code
   - Время выполнения
   - Вывод (stdout/stderr)

### Просмотр логов

1. Перейдите в "Logs"
2. Используйте фильтры:
   - Level (INFO, WARNING, ERROR, DEBUG)
   - Category (connection, execution, system, auth)
   - Time Range
3. Экспортируйте логи в CSV при необходимости

## Безопасность

### Шифрование секретов

Все gsocket secrets хранятся в базе данных в зашифрованном виде с использованием AES-256-GCM.

### Аутентификация

Используется JWT токены с временем жизни 8 часов. Пароли хешируются с использованием bcrypt.

### Смена пароля

Пользователи могут изменить свой пароль в разделе **Settings → Security & Account**:
- Требуется текущий пароль для подтверждения
- Новый пароль должен быть минимум 8 символов
- Пароли должны совпадать при подтверждении

### Требования к паролям

**Минимальные требования:**
- Минимум 8 символов при смене пароля
- Рекомендуется использовать комбинацию букв, цифр и спецсимволов

**Пароль администратора по умолчанию:**
- Логин: `admin`
- Пароль: `Admin123456!`
- ⚠️ **Обязательно смените после первого входа!**

## Мониторинг

Monitor service автоматически проверяет доступность всех хостов каждые 3 минуты:

- Отправляет простую команду `echo 'ping'` через gsocket
- Обновляет статус хоста (online/offline)
- Записывает историю доступности в ping_history
- Логирует изменения статуса

## Troubleshooting

### База данных не инициализируется

```bash
# Удалите старую базу и пересоздайте
rm data/c2panel.db
python scripts/init_db.py
python scripts/create_admin.py
```

### Не могу подключиться к хосту

1. Проверьте, что gsocket установлен на целевом хосте
2. Убедитесь, что secret правильный
3. Проверьте сетевую доступность
4. Увеличьте значение timeout в настройках

### Ошибка "Unauthorized"

1. Проверьте, что токен авторизации действителен
2. Войдите заново через `/login`
3. Проверьте настройки SECRET_KEY в .env

## Автоматизация развертывания

### Полное обновление и ребилд

Для обновления кода из репозитория и ребилда контейнеров:

```bash
./deploy.sh
```

Скрипт автоматически:
- Создает резервную копию базы данных
- Проверяет наличие обновлений в git
- Останавливает контейнеры
- Пересобирает Docker образы
- Запускает обновленные контейнеры
- Показывает статус и логи

### Быстрое обновление

Для быстрого обновления без полного ребилда:

```bash
./update.sh
```

Это выполнит:
- `git pull` для получения последних изменений
- Перезапуск контейнеров

### Дополнительные команды

```bash
# Посмотреть логи
./deploy.sh <branch> logs

# Проверить статус контейнеров
./deploy.sh <branch> status

# Остановить контейнеры

./deploy.sh <branch> start

./deploy.sh <branch> restart

# Создать резервную копию БД
./deploy.sh <branch> backup
```

При добавлении хоста через Web UI укажите "Custom GSRN Server":
